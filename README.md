# CA-ADS Nexus 

Plataforma web oficial do **Centro Acadêmico de Análise e Desenvolvimento de Sistemas (CA-ADS)** do IFSP - Campus São Paulo. 

Um projeto desenvolvido com foco em alta performance, UI/UX futurista (Dark Mode & Glassmorphism), transições fluidas com GSAP e efeitos visuais imersivos.

---

##  Tecnologias Utilizadas

Este projeto foi construído utilizando uma stack moderna de desenvolvimento front-end:

* **React** + **TypeScript (TSX)** — Estruturação de componentes modulares e tipados.
* **Tailwind CSS** — Estilização avançada com Design System customizado (Dark/Neon).
* **GSAP (GreenSock)** — Animações de entrada, *staggers* e interações refinadas.
* **Three.js** — Fundo 3D interativo com partículas e otimização por tiers de hardware.
* **Vite** — Empacotador de alta velocidade para desenvolvimento e build.
* **PWA (Vite Plugin PWA)** — Suporte a cache e modo offline para os estudantes.

---

##  Módulos da Aplicação

1. **Hero Section & Navegação:** Header fixo translúcido com *backdrop-blur*, indicador animado e atalhos fluidos.
2. **Banco de Provas & Conteúdos:** Repositórios organizados por período do curso com transições de elevação (*hover lift*).
3. **Grade de Horários & Salas:** Tabela interativa para consulta rápida das aulas noturnas e docentes.
4. **Central de Links & Comunidades:** Acesso rápido ao WhatsApp oficial, Instagram e grupos específicos de matérias.
5. **Planta Interativa do Campus:** Mapa vetorial dark minimalista com navegação dinâmica pelos blocos de A a H e suas respectivas salas.
6. **Tutoriais e Acessos Úteis:** Guias rápidos para o AVA/Moodle, SUAP e orientações aos calouros.
